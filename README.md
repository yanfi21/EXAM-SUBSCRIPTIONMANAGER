# Менеджер личных задач и заметок

Учебный проект по техническому заданию (ГОСТ 34.601-90, ГОСТ 34.602-2020, ISO/IEC 25010, ISO/IEC/IEEE 29148).
Приложение предназначено для создания, хранения и упорядочивания личных задач и заметок с поиском,
фильтрацией, отметкой выполнения и визуализацией данных.

Репозиторий содержит **две независимые реализации одного ТЗ**:

| Каталог | Вариант ТЗ | Стек |
| --- | --- | --- |
| [`angular-app/`](angular-app) | Вариант A | Angular 20 (standalone, Signals), Angular Router, Reactive Forms, Angular CDK Drag & Drop, SCSS + Tailwind CSS 4, Vitest |
| [`react-app/`](react-app) | Вариант B | React 19, Vite, TypeScript, React Router, Zustand, React Hook Form, dnd-kit, Tailwind CSS 4, Vitest |

Данные обеих версий хранятся в `localStorage` браузера, внешний сервер не требуется.
Формат выгрузки JSON совместим: резервную копию из Angular-версии можно импортировать в React-версию и наоборот.

## Быстрый старт

```bash
# вариант A — Angular (http://localhost:4200)
cd angular-app
npm install
npm start

# вариант B — React (http://localhost:5173)
cd react-app
npm install
npm run dev
```

Сборка и тесты:

```bash
cd angular-app && npm run build && npm test     # 43 теста, Vitest + jsdom
cd react-app   && npm run build && npm test     # 41 тест, Vitest + jsdom
```

## Функциональность (раздел 3 ТЗ)

- **Задачи** — заголовок, описание, приоритет (низкий/средний/высокий), дедлайн, теги, статус.
- **Редактирование и удаление** — изменение любых полей, мягкое удаление и восстановление из корзины,
  безвозвратное удаление по требованию.
- **Отметка выполнения** — переключение «выполнено / не выполнено» одним кликом, фиксация даты завершения.
- **Поиск** — по названию, описанию и тегам в реальном времени (все слова запроса).
- **Фильтрация и сортировка** — по статусу, приоритету, тегам, просроченным; сортировка по дате создания,
  дедлайну, приоритету, названию и статусу; последние настройки сохраняются.
- **Заметки** — создание, редактирование, удаление, поиск, Markdown-подобное форматирование с предпросмотром.
- **Представления** — список, канбан-доска с drag & drop («К выполнению», «В работе», «Выполнено»),
  календарь по дедлайнам с выбором дня и быстрым созданием задачи.
- **Тёмная/светлая тема** — переключение в шапке, по клавише `T` и в настройках; учитывается системная тема.
- **Экспорт/импорт** — выгрузка снимка данных в JSON и загрузка файла в режимах «объединить» и «заменить»
  с валидацией и миграцией устаревших записей.
- **Статистика** — выполнено за 7 и 30 дней, просроченные, задачи на сегодня, процент выполнения,
  срез по текущей неделе, распределение по приоритетам и популярные теги.
- **Обратная связь** — форма с сохранением отзыва в `localStorage` и ссылкой `mailto`, адрес поддержки в футере.
- **Задача дня** — ближайшая по дедлайну задача и мотивационная цитата (публичный API с локальным фолбэком).
- **Горячие клавиши** — `N` (новая задача), `/` (поиск), `T` (тема).

## Хранимые данные (раздел 4 ТЗ)

| Ключ `localStorage` | Содержимое |
| --- | --- |
| `tasknotes.tasks` | задачи: `id, title, description, priority, status, dueDate, tags, createdAt, updatedAt, completedAt, deletedAt` |
| `tasknotes.notes` | заметки: `id, title, content, createdAt, updatedAt, deletedAt` |
| `tasknotes.preferences` | тема, предпочитаемое представление, последние фильтры и сортировка |
| `tasknotes.feedback` | отзывы из формы обратной связи |
| `tasknotes.schemaVersion` | версия схемы данных для миграций |

Корзина не выделена в отдельный ключ: удалённые записи хранятся вместе с остальными и помечаются полем
`deletedAt` (мягкое удаление), что упрощает восстановление и синхронизацию в будущем.

## Качество (раздел 9 ТЗ)

- **Функциональная полнота** — реализованы все функции раздела 3 ТЗ в обеих версиях.
- **Производительность** — фильтрация и поиск выполняются над плоскими массивами через мемоизацию
  (`computed` в Angular, `useMemo`/селекторы Zustand в React); отклик интерфейса на 1000 задач < 100 мс.
- **Удобство** — mobile-first вёрстка, поддержка клавиатуры, видимый фокус, ARIA-атрибуты, тёмная тема.
- **Надёжность** — запись в `localStorage` при каждом изменении, защита от повреждённых данных и
  недоступного хранилища (fallback в память), восстановление состояния после перезагрузки.
- **Сопровождаемость** — модульная структура, строгий TypeScript, общие доменные утилиты, 84 автотеста.
