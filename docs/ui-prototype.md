# Эскизный проект (прототип интерфейса)

Стадия 4 по ГОСТ 34.601-90. Прототип описывает структуру экранов, навигацию и состояния интерфейса,
единые для обеих реализаций (Angular и React).

## 1. Карта экранов

```
/                       → редирект на предпочитаемое представление
/tasks/list             Список задач
/tasks/board            Канбан-доска
/tasks/calendar         Календарь дедлайнов
/notes                  Заметки
/stats                  Статистика
/trash                  Корзина
/settings               Настройки, данные, обратная связь
*                       Страница «не найдено»
```

## 2. Общий каркас

```
┌───────────────┬──────────────────────────────────────────────────────────┐
│  Боковое меню │  Шапка: заголовок экрана · [тема] · [+ Новая задача]      │
│  • Список     ├──────────────────────────────────────────────────────────┤
│  • Доска      │                                                          │
│  • Календарь  │   Рабочая область (router-outlet / <Outlet/>)            │
│  • Заметки    │                                                          │
│  • Статистика │                                                          │
│  • Корзина    │                                                          │
│  • Настройки  ├──────────────────────────────────────────────────────────┤
│  Горячие кл.  │  Футер: название, версия, email поддержки                 │
└───────────────┴──────────────────────────────────────────────────────────┘
```

На экранах шириной менее 1024 px боковое меню сворачивается в кнопку-гамбургер, карточки
перестраиваются в одну колонку, канбан-доска показывает колонки вертикально (mobile-first).

## 4. Экран «Канбан-доска»

Три колонки — «К выполнению», «В работе», «Выполнено». Карточку можно перетащить мышью или с клавиатуры;
при переносе меняется статус, внутри колонки сохраняется порядок. Пустая колонка показывает подсказку
«Перетащите задачу сюда», в заголовке колонки — счётчик и кнопка быстрого создания.

## 5. Экран «Календарь»

Месячная сетка 7 × 6 с переключением месяцев и кнопкой «Сегодня». В ячейке — до двух задач
(просроченные выделены красным, выполненные — зачёркнуты) и счётчик «ещё N». Справа — панель выбранного
дня со списком задач и кнопкой создания задачи на эту дату; ниже — блок «Без дедлайна».

## 6. Экран «Заметки»

Поиск по заголовку и тексту, кнопка «Новая заметка», плитка карточек (1–3 колонки по ширине экрана).
В диалоге редактирования — переключатель «Редактор / Предпросмотр» для Markdown-подобной разметки.

## 7. Экран «Статистика»

Четыре карточки показателей (всего, выполнено, просрочено, в работе), блок «Выполнено за период»
(7 и 30 дней) с графиком текущей недели, распределение по приоритетам, популярные теги и список
просроченных задач с переходом в редактирование.

## 8. Экран «Корзина»

Сводка по количеству удалённых элементов, кнопка «Очистить корзину» с диалогом подтверждения,
отдельные секции для задач и заметок с действиями «Восстановить» и «Удалить навсегда».

## 9. Экран «Настройки»

Тема оформления, представление по умолчанию, экспорт/импорт JSON (режимы «объединить»/«заменить»),
форма обратной связи с оценкой и ссылкой `mailto`, список сохранённых отзывов, загрузка демо-данных
и удаление всех данных с подтверждением.

## 10. Состояния и обратная связь интерфейса

- **Пустые состояния** — отдельный блок с иконкой, пояснением и основным действием.
- **Ошибки форм** — подпись под полем, выделение рамки, блокировка отправки.
- **Уведомления** — всплывающая плашка внизу экрана, для удаления доступно действие «Вернуть».
- **Подтверждения** — модальное окно для необратимых операций.
- **Клавиатура** — `N` создаёт задачу, `/` фокусирует поиск, `T` меняет тему, `Esc` закрывает диалог.
