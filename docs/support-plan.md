# План сопровождения, обратная связь и развитие

Стадия 8 по ГОСТ 34.601-90 (разделы 6–8 ТЗ).

## 1. План сопровождения на 2 года

| Период | Мероприятия | Результат |
| --- | --- | --- |
| 0–3 мес. | приём обращений, исправление дефектов, стабилизация работы с `localStorage`, правка UI-багов, проверка на основных браузерах | реестр дефектов, патч-релизы 1.0.x |
| 3–6 мес. | обновление зависимостей (Angular, React, Vite, Tailwind), оптимизация рендеринга списков, кеширование результатов фильтрации | релиз 1.1 с обновлённым стеком |
| 6–12 мес. | новые представления (например, группировка по тегам), улучшение UX по отзывам, оптимизация при более чем 1000 задач, виртуализация списка | релиз 1.2 |
| 12–24 мес. | поддержка синхронизации (опционально), миграции схемы данных по `schemaVersion`, рефакторинг и снижение технического долга | релиз 2.0 |

### Регламент работ

- Приоритеты обращений: блокирующий — 1 рабочий день, серьёзный — 3 рабочих дня,
  незначительный — в ближайший плановый релиз.
- Перед каждым релизом: `npm test` и `npm run build` в обоих приложениях, ручной прогон
  сценариев «создание → фильтрация → канбан → экспорт → импорт».
- Изменения схемы данных сопровождаются увеличением `tasknotes.schemaVersion` и функцией миграции
  в модуле нормализации (`backup.util.ts` / `backup.ts`).

## 2. Каналы обратной связи

- **Форма в приложении** — раздел «Настройки»: имя, email, оценка (1–5), сообщение.
  Отзыв сохраняется в `localStorage` (ключ `tasknotes.feedback`) и доступен в списке последних отзывов.
- **Отправка письмом** — кнопка «Написать письмом» формирует `mailto` с темой обращения.
- **Email поддержки** — `support@tasknotes.app`, указан в футере каждого экрана.
- **Issues репозитория** — для технических обращений и предложений по развитию.

| Повторяющиеся задачи | правила повторения (ежедневно, еженедельно, по дням недели) | 6–12 мес. |
| Вложения к заметкам | изображения и файлы с хранением в IndexedDB | 12–18 мес. |
| Голосовой ввод задач | Web Speech API, распознавание заголовка и дедлайна | 18–24 мес. |

## 4. Риски сопровождения

| Риск | Последствие | Мера снижения |
| --- | --- | --- |
| Переполнение `localStorage` | потеря новых данных | контроль объёма в настройках, регулярный экспорт JSON, предупреждение при ошибке записи |
| Очистка данных браузера | полная потеря задач | напоминание о резервной копии, экспорт в JSON |
| Несовместимое обновление схемы | ошибки чтения данных | версия схемы и нормализация записей при загрузке |
| Недоступность внешнего API цитат | пустой блок «Задача дня» | локальный набор цитат как резервный источник |
