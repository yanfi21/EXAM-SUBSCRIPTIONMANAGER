# Техническое задание на создание веб-приложения «Менеджер личных задач и заметок»

## 1. Общие сведения

Наименование системы: веб-приложение «Менеджер личных задач и заметок».
Разработка ведётся в соответствии с ГОСТ 34.601-90.

Источники разработки:

- ГОСТ 34.602-2020 — Техническое задание на создание автоматизированной системы.
- ГОСТ 34.601-90 — Стадии создания автоматизированных систем.
- ISO/IEC 25010 — Модель качества программного продукта.
- ISO/IEC/IEEE 29148 — Процессы инженерии требований.

## 2. Назначение и цели создания системы

**Назначение.** Приложение предназначено для создания, хранения и упорядочивания личных задач и заметок
с возможностью фильтрации, поиска и отметки выполнения.

**Цели:**

- предоставить простой интерфейс для управления задачами и заметками;
- обеспечить быстрый поиск и фильтрацию по статусу, приоритету и тегам;
- показывать данные в удобном визуальном виде (список, канбан-доска, календарь).

## 3. Функционал

| Функция | Требование ТЗ | Реализация |
| --- | --- | --- |
| Создание задачи | заголовок, описание, приоритет, дедлайн, теги | форма задачи (Reactive Forms / React Hook Form) с валидацией |
| Редактирование и удаление | изменение полей, мягкое удаление с восстановлением | поле `deletedAt`, раздел «Корзина», действие «Вернуть» в уведомлении |
| Отметка выполнения | переключение «выполнено / не выполнено» | чекбокс в карточке, быстрые кнопки статусов, фиксация `completedAt` |
| Поиск задач | по названию и описанию в реальном времени | поиск по заголовку, описанию и тегам, все слова запроса |
| Фильтрация и сортировка | статус, приоритет, дедлайн, теги | фильтры + 5 полей сортировки, сохранение последних настроек |
| Заметки | создание, редактирование, удаление, Markdown (опционально) | CRUD, поиск, собственный Markdown-рендерер с предпросмотром |
| Представления | список, канбан-доска, календарь | три маршрута, drag & drop на доске, месячная сетка в календаре |
| Тёмная/светлая тема | переключение оформления | переключатель в шапке, клавиша `T`, учёт системной темы |
| Экспорт/импорт | выгрузка в JSON и загрузка из файла | снимок данных со схемой версии, режимы «объединить» и «заменить» |
| Статистика | выполнено за неделю/месяц, просроченные | карточки показателей, недельный график, распределение по приоритетам и тегам |

## 4. Хранимые данные (localStorage)

- Список задач: `id`, `title`, `description`, `priority`, `status`, `dueDate`, `tags`, `createdAt`,
  `updatedAt`, `completedAt`, `deletedAt`.
- Список заметок: `id`, `title`, `content`, `createdAt`, `updatedAt`, `deletedAt`.
- Предпочитаемое представление: список / канбан / календарь.
- Выбранная тема оформления: `light` / `dark`.
- Настройки фильтров и сортировки (последние использованные).
- Корзина: удалённые задачи и заметки (помечены полем `deletedAt`).

Внешний источник данных отсутствует — всё хранится локально. Опционально используется публичный API цитат
для блока «Задача дня» с локальным резервным набором цитат при недоступности сети.

## 5. Технологическая реализация

**Вариант A — Angular (`angular-app/`):**

- Angular 20, standalone-компоненты, Signals для реактивности;
- Angular Router для навигации между представлениями;
- Reactive Forms для форм задачи и заметки;
- сервис `StorageService` для работы с `localStorage`;
- Angular CDK (Drag & Drop) для канбан-доски;
- SCSS + Tailwind CSS для стилей.

**Вариант B — React (`react-app/`):**

- React 19, Vite, TypeScript;
- React Router для навигации;
- Zustand для состояния;
- React Hook Form для форм;
- dnd-kit для канбан-доски;
- Tailwind CSS для стилей.

## 7. Каналы обратной связи

- Форма обратной связи в приложении: отзыв сохраняется в `localStorage`, предусмотрена отправка
  письмом через `mailto`.
- Email поддержки указан в футере приложения: `support@tasknotes.app`.

## 8. Внесение изменений в приложение (перспективы)

- Синхронизация с облаком (Firebase / Supabase).
- Напоминания и push-уведомления (Notification API).
- Совместная работа над задачами (шаринг списков).
- Поддержка нескольких языков (i18n).
- Повторяющиеся задачи (recurring tasks).
- Вложения к заметкам (изображения, файлы).
- Голосовой ввод задач (Web Speech API).

## 9. Требования к качеству (ISO/IEC 25010)

- **Функциональная полнота** — все заявленные функции работают без ошибок.
- **Производительность** — отклик интерфейса < 100 мс при 1000 задач, поиск < 50 мс.
- **Удобство использования** — интуитивный интерфейс, поддержка клавиатуры, адаптивность (mobile-first).
- **Надёжность** — сохранение данных в `localStorage` при каждом изменении, восстановление после перезагрузки.
- **Сопровождаемость** — модульная структура, TypeScript, покрытие ключевых сервисов тестами.
